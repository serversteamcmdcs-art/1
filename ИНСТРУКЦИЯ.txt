# 🎨 PaintAI - Графический редактор

Простое и удобное приложение для рисования, созданное на React.

---

## 📱 Запуск на компьютере (Windows/Mac/Linux)

### Необходимые программы:
1. **Node.js** (версия 16 или выше) - скачать с [nodejs.org](https://nodejs.org/)

### Шаги для запуска:

1. **Установите Node.js** (если ещё не установлен):
   - Перейдите на [nodejs.org](https://nodejs.org/)
   - Скачайте версию LTS
   - Установите, следуя инструкциям установщика

2. **Распакуйте архив** с проектом в любую папку

3. **Откройте терминал/командную строку** в папке проекта:
   - Windows: Откройте папку → Зажмите Shift + ПКМ → "Открыть окно PowerShell здесь"
   - Mac/Linux: Откройте Terminal и перейдите в папку командой `cd путь/к/папке`

4. **Установите зависимости** (выполните команду):
   ```bash
   npm install
   ```

5. **Запустите приложение**:
   ```bash
   npm start
   ```

6. **Откройте браузер** - приложение автоматически откроется по адресу:
   ```
   http://localhost:3000
   ```

## 📲 Запуск на телефоне (iOS/Android)

### Способ 1: Через локальную сеть (телефон и компьютер в одной Wi-Fi сети)

1. **Запустите приложение на компьютере** (см. инструкцию выше)

2. **Узнайте IP-адрес компьютера**:
   - Windows: Откройте командную строку → введите `ipconfig` → найдите "IPv4-адрес" (например, 192.168.1.100)
   - Mac: Системные настройки → Сеть → Wi-Fi → найдите IP-адрес
   - Linux: Введите `hostname -I` в терминале

3. **На телефоне откройте браузер** и введите:
   ```
   http://ВАШ_IP:3000
   ```
   Например: `http://192.168.1.100:3000`

4. **Добавьте на главный экран** (опционально):
   - iOS Safari: Нажмите "Поделиться" → "На экран Домой"
   - Android Chrome: Меню (⋮) → "Добавить на главный экран"

### Способ 2: Развернуть онлайн (бесплатно)

#### Вариант A: Vercel (рекомендуется)
1. Создайте аккаунт на [vercel.com](https://vercel.com)
2. Установите Vercel CLI: `npm i -g vercel`
3. В папке проекта выполните: `vercel`
4. Следуйте инструкциям - получите ссылку на сайт

#### Вариант B: Netlify
1. Создайте аккаунт на [netlify.com](https://netlify.com)
2. Соберите проект: `npm run build`
3. Перетащите папку `build` на сайт Netlify
4. Получите ссылку на сайт

#### Вариант C: GitHub Pages
1. Создайте репозиторий на GitHub
2. Добавьте в package.json: `"homepage": "https://ваш-логин.github.io/paintai"`
3. Установите: `npm install gh-pages --save-dev`
4. Добавьте в scripts: `"deploy": "npm run build && gh-pages -d build"`
5. Выполните: `npm run deploy`

## 🛠 Возможные проблемы и решения

### "npm не найден"
→ Переустановите Node.js, перезапустите компьютер

### "Порт 3000 занят"
→ Закройте другие приложения или измените порт: `set PORT=3001 && npm start` (Windows)

### Не открывается с телефона
→ Проверьте, что телефон и компьютер в одной Wi-Fi сети
→ Временно отключите брандмауэр/антивирус

### Ошибки при npm install
→ Удалите папку `node_modules` и файл `package-lock.json`, затем снова выполните `npm install`
